# «Важный комок» — PHONK1S, музыкальный клип

Процедурный 2.5D-клип в стиле печатной манги: тушь с «дрожащим» контуром (line boil, 12 fps),
растровый полутон, красный акцент, фактура бумаги. Перспективная 3D-камера над сценой-диорамой
(стены, пол и персонажи — плоскости в пространстве), камера шагает в такт биту, инверсия кадра на ударах.

Рендер: Python + skia-python, кодирование ffmpeg. Аудио в репозиторий не входит.

```
SS=1 FPS=60 python phmain.py range <first_frame> <last_frame> out.mp4   # 1920×1080, 60 fps
SS=1 python phmain.py still sheet.jpg 10 20 30                          # контрольные кадры
```

Ожидает `/tmp/ph/song.wav` и `/tmp/ph/beats.json` (сетка бита, см. `core.py`).
